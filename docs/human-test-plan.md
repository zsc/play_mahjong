# 本轮训练与人测候选判据

计划日期：2026-10-26；在本轮模型开发集/holdout 评估前固定。

- 优化规则核心的执行速度，不改变现有阶段一语义。继续明确标注不是完整 MCR。
- 新 teacher 数据：`qualified-tenpai`，30,000 局，种子 `13000000..13029999`。
  与旧 30k 数据分别保存，不复用旧任务的未落盘结果。
- BC：两层 256 MLP、40 epochs、batch 4096、学习率 0.001、花色增强、按完整对局划分验证集。
  训练只学习标准弃牌；其他动作由 `qualified-tenpai` scaffold 处理。
- PPO：从 BC 初始化，三名冻结 `qualified-tenpai` 对手，40 updates × 480 局，
  种子 `14000000..14019199`，学习率 5e-5，teacher BC 系数 0.5，每 10 updates 保留快照。
- 开发集：`6700000..6701599`，1,600 局，候选席位按 0/1/2/3 轮换。
  比较 BC、PPO 快照及教师；原始策略与 `teacher-optimal` 保护配置分别记录，不混合报告。
- 最终 holdout：`6600000..6606399`，6,400 局；在开发集选定候选及配置后才使用，
  不用于调参。若本轮失败而继续调参，下一轮最终验收必须使用新 seed 段。

“值得人测”在本轮指：

1. 真实训练、非 smoke 权重、契约匹配、推理与回放可运行，所有选择经合法动作校验。
2. 对三名冻结 qualified 对手，候选相对闭门教师的配对净得分差 95% CI 下界大于 0。
3. 相对 qualified 教师，配对差 95% CI 下界大于 -1 分/盘。
   这是预先选择的人测非劣界限，不代表统计证明模型强于 qualified 教师。
4. 同时报告样本数、净得分、和牌/放炮/流局率、实际学习范围、scaffold 和 guard。
5. ONNX/PyTorch 数值对照通过，并能通过本地入口让真人选择所有合法动作。

如果仅受保护配置达到门槛，必须称为“训练模型 + 启发式保护”的复合候选。
不得将启发式优势归功于神经网络；也不得把本轮阶段一结果描述成完整国标麻将棋力。
若没有配置通过门槛，继续训练/改进并公开失败结果，不能只换一个好看的 seed 段宣称成功。
