# 全动作模型、对手池与自博弈实验（2026-10-26）

目标：模型在推理时只受正式合法动作 mask 约束，不使用弃牌保护，也不把吃碰杠胡交给启发式。
规则仍为 mcr-wmo2006-stage1；没有删减现有动作或改写结算。v6 可见特征含结构向听等计算特征，
“全动作网络”不表示不使用结构特征。完整 MCR 的既有缺口仍在。

## 先固定实验与验收

- 旧基准固定为网页 PPO40 SHA `1f865a82f1d0ff30266ec9ae0857993bb600700727de3799987b2f86b390dc62`，teacher-optimal + qualified scaffold。
- 新模型 `tile-shared-v1`：共享牌种评分器，学习所有合法动作。无规则排序写入 logits，无额外保护 mask。
  critic 改为线性输出，避免高番正式分数/64 超出 tanh 表示范围。
- 蒸馏：从旧模型热启动，在当前网页策略与学生混合产生的可见局面上学习网页策略动作。
  教师仅用于训练标签/对手；混合行为阶段只运行监督损失，不把它冒充 on-policy PPO。
- PPO：每批先冻结 learner 和全部对手；25% 四家同策略自博弈，其余对手从网页策略、qualified、
  最近四个冻结历史快照抽取。历史池仅在批次之间更新，每成员保存 checkpoint SHA。
  按玩家分别计算 GAE，正式终局收益/64，gamma=1，无奖励塑形；每个玩家最后一条决策都得到终局分。
- 所有实际可选动作均采样。单一合法动作窗口由原生引擎执行，不改变玩家选择；该动作不算学习时间步。
- 蒸馏种子 50,000,000 起，最多 131,072 盘。PPO 四分支种子起点 52/54/56/58 百万，各最多 524,288 盘。
  开发测试 60,000,000..60,000,999，每副牌墙四座，按原始净分选择 snapshot。
  开发排序分为“相对旧策略对 qualified 的配对增益”和“对三个旧策略的直接均分”的等权平均；
  两项开发均值均为正才考虑最终验收，不用训练 loss 排名。
- 最终验收保留 **62,000,000..62,015,999**，在开发集选定一个候选且有改善后才启用。
  冻结候选 SHA，不能看完 holdout 再换 snapshot 复测同一批种子。
- 网页替换同时要求：新全动作网络对三个 qualified 的成绩，相对旧网页策略的同墙配对差 95% CI 下界 > 0；
  新网络对三个旧网页策略的直接对战平均净分 95% CI 下界 > 0。两项均按 16,000 副独立牌墙分组。
  未通过就保留原网页模型，不以“无显著差异”替代“已超过”。

## 复现入口

`training/league.py --help`：distill/PPO、历史对手池、原始对手分配记录和精确恢复。
`training/arena.py --challengers new-full,old-guard --opponents qualified,old-guard`：全动作裸策略验收。

新增 `decision_batch` 仍调用同一 OCaml 核心，批次非法请求原子回滚，校验 revision。
旧 discard-only 训练入口保持兼容。模型导出记录架构、全动作范围、无保护和线性 value。

实际任务、开发结果与最终结论在运行后补录；本计划本身不代表已经提升棋力。
