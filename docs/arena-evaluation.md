# 棋力测量：冻结策略、同墙四座、按牌墙分组

2026-10-26，用户要求测棋力后新增。此前报告每个 seed 只打一次，模型席位跨 seed 轮换；
这里改为每一副固定牌墙分别坐东南西北再打一盘，以减少座位差异。四盘共享牌墙，
置信区间必须先按牌墙分组，不能把四盘当作四个独立样本。

## 预先固定的正式测试

- 旧模型：当前网页 PPO40，SHA `1f865a82f1d0ff30266ec9ae0857993bb600700727de3799987b2f86b390dc62`。
- 新模型：SOFY b2-u32，SHA `ceb031e49c0d57631e081d71393995290c88e19ff104c9edb955df72e5ed06e2`。
- 主测试：40,000,000..40,007,999，共 8,000 副牌墙；每个策略 32,000 盘。
  old-guard/new-guard/old-raw/new-raw/qualified 五策略，对手均为三个 qualified。
  主比较是 new-guard 与 old-guard 的同 seed/seat 正式净分差，按 8,000 个牌墙均值计算 95% CI。
- 次测试：41,000,000..41,000,999，共 1,000 副牌墙；old-guard/new-guard/qualified
  分别对战三个 closed 或三个 old-guard，合计 24,000 盘。新旧直接对战结果用于补充，不替代主比较。
- 合计 **184,000 盘**。模型和配置在测试前固定；不从这些结果再挑 checkpoint。
  次要比较为探索性结果，不能从多项中只挑最好的一项宣称总体提升。
- raw 仅指没有 teacher-optimal 弃牌保护，吃碰杠胡和花牌仍由 qualified-tenpai scaffold 处理；不是全动作纯神经网络。

## 可复现入口

```sh
python training/arena.py --old <旧checkpoint> --new <新checkpoint> \
  --output training/runs/arena-primary --seed-start 40000000 --seeds 8000 --workers 48
python training/arena.py --old <旧checkpoint> --new <新checkpoint> \
  --output training/runs/arena-secondary --seed-start 41000000 --seeds 1000 --workers 32 \
  --challengers old-guard,new-guard,qualified --opponents closed,old-guard
```

入口保存模型 hash、引擎二进制和源码 hash、特征/动作版本、随机种子、每盘结果和分组统计。
所有棋力指标都是冻结推理的正式净分、和牌、放炮、流局；不是 PPO loss 或训练采样中的胜负计数。
同一模型控制四家的零均分仅作为分数/轮座正确性校验，不当作强度证据。

## 人测

在网页用未打过的种子，记录完整的连续 20–50 盘，终局保存回放，避免只挑赢牌或输牌局。
先不看 AI 建议，复盘时再查看。重点记录违反常识的弃牌、合法胡牌遗漏、吃碰杠取舍和规则问题。
少量真人对局更适合找具体弱点；麻将波动大，不能从几盘输赢直接下强弱结论。

目前仍是 stage1 单盘测试。完整 MCR 规则、整场名次和外部强 AI 对标未验收，不能据此声称国标段位、Elo 或专业牌手水平。

## 实际结果（2026-10-26）

SOFY 任务 59346、59347 均已成功结束。主测试每策略 32,000 盘，8,000 个独立牌墙组：

| 策略 | 平均净分 / 盘 | 95% CI | 和牌率 | 放炮率 | 流局率 |
| --- | ---: | --- | ---: | ---: | ---: |
| 当前网页模型 + 保护 | +0.240 | [0.052, 0.428] | 23.54% | 15.00% | 7.65% |
| 新 PPO + 保护 | +0.293 | [0.091, 0.495] | 23.56% | 14.90% | 7.63% |
| 旧模型，无弃牌保护 | -0.507 | [-0.764, -0.250] | 22.26% | 14.76% | 7.97% |
| 新模型，无弃牌保护 | -0.236 | [-0.500, 0.028] | 22.56% | 14.46% | 7.98% |

预先指定的主比较，新旧带保护模型配对差 **+0.0528，95% CI [-0.1403, 0.2459]**。
没有证据证明本轮大规模 PPO 已提升部署策略；网页继续使用旧候选。
当前复合策略在该冻结对手配置有小幅正收益，但去除保护后性能下降，不能归因于纯网络能力。
此处除主比较外的区间是未作多重比较校正的探索性区间。

次测试每配置 4,000 盘：新模型对三个旧模型 +0.3675，CI [-0.1746, 0.9096]，
也未证明直接对战优势。对三个 closed，旧模型 +1.0475，新模型 +0.7493；
新旧配对差 -0.2983，CI [-0.8664, 0.2699]。不能只报告有利的一组。
